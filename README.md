# Rajutanku

Website toko rajutan handmade (HTML/CSS/JS murni, tanpa build step).

Jalankan lokal:

```bash
python3 -m http.server 8000
# buka http://localhost:8000
```

Checkout dan form custom diarahkan ke WhatsApp melalui `wa.me` — nomor toko diatur di konstanta `STORE.whatsappNumber` pada `app.js`. Produk beserta harga dan stok berada di array `PRODUCTS` di file yang sama.
